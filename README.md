# 1AudioTool releases

Signed desktop builds of 1AudioTool and the update metadata installed copies read.

## Download

Get the current build for macOS and Windows at **[1audiotool.com/download](https://1audiotool.com/download)**.

Every version, with its installers and signatures, is listed under [Releases](https://github.com/stoicsoft/1AudioTool-releases/releases).

## What each release carries

- `1AudioTool_<version>_aarch64.dmg` and `_x64.dmg`, for Apple Silicon and Intel Macs
- `1AudioTool_<version>_x64-setup.exe`, for Windows
- `.app.tar.gz` and `-setup.exe` updater bundles, each with a `.sig` signature
- `latest.json`, the manifest the app checks for updates
